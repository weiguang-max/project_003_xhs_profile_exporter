# 小红书用户主页笔记导出插件

Chrome Manifest V3 插件，使用 Chrome Side Panel 在浏览器原生侧边栏中提供采集工具，自动慢速滚动，采集小红书用户主页公开展示的笔记卡片，并按需读取详情正文和封面图片链接，导出为单表 Excel 文件或导入飞书多维表格。

## 功能

- 仅支持 `https://www.xiaohongshu.com/user/profile/...` 用户主页。
- 点击扩展图标打开或切换 Chrome Side Panel，网页本身不会被插件 DOM 遮挡。
- 自动滚动并采集已加载的候选笔记，达到候选数量或页面到底后停止。
- 点赞阈值只用于筛选候选笔记，不用于决定继续滚动采集。
- 按笔记链接去重。
- 笔记链接优先保留小红书页面里的 `xsec_token`、`xsec_source` 参数。
- 支持按内容类型筛选：全部、图文、视频；可与点赞阈值同时使用。
- 面板实时展示封面缩略图、标题、作者昵称、笔记形式、点赞数。
- 点击筛选结果可快速定位并打开对应的笔记详情悬浮层。
- 可按当前筛选顺序逐条抓取笔记正文和第一张主图 URL。
- 支持按点赞数从高到低排序。
- 导出 `.xlsx` 文件。
- 导入飞书多维表格，并按 `原文链接` 跳过重复记录。
- 飞书字段固定为：`标题`、`作者`、`笔记形式`、`点赞`、`原文链接`、`正文`、`封面`（附件类型）。

插件只读取当前浏览器页面公开展示的数据，不登录、不保存账号信息、不绕过访问限制、不调用小红书内部接口。详情抓取通过当前页面的公开详情悬浮层完成；导入飞书时会下载封面图片并上传到目标多维表格。为触发小红书主页的真实卡片点击，扩展使用 Chrome `debugger` 权限向当前标签页发送鼠标输入，不会新开标签页。

## 安装

1. 打开 Chrome 的扩展程序管理页。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `extension/` 目录。

首次加载或更新版本时，Chrome 会提示扩展使用“调试器”权限。这是为了让扩展能够在当前标签页发送鼠标按下和抬起事件，触发与手动点击一致的详情悬浮层；扩展只在用户点击定位或抓取按钮时使用该能力，并在每次点击后立即断开调试连接。

## 使用

1. 打开一个小红书用户主页，例如：

   ```text
   https://www.xiaohongshu.com/user/profile/...
   ```

2. 点击浏览器工具栏里的插件图标，Chrome 右侧会打开 Side Panel。
3. 设置“筛选点赞数≥”，默认 `0`。
4. 设置“内容类型”，默认 `全部`。
5. 设置“候选笔记数”，默认 `300`。这里表示先从主页采集前 300 条候选笔记，再按点赞阈值和内容类型筛选。
6. 点击“开始采集 博主笔记”。
7. 等待状态显示采集完成，或再次点击按钮停止。
8. 可点击“点赞排序”调整面板列表和导出顺序；点击任意结果可定位并打开笔记详情。
9. 点击“抓取正文”按当前筛选顺序逐条读取正文和封面链接，可再次点击停止。
10. 点击“导出 Excel”，或点击右侧“导入飞书”。

## 导入飞书多维表格

目标多维表格需要提前创建这些字段：

1. 标题
2. 作者
3. 笔记形式
4. 点赞
5. 原文链接
6. 正文
7. 封面（附件类型）

使用步骤：

1. 在飞书开放平台创建自建应用，并确保应用有读取和写入目标多维表格记录的权限。
2. 把自建应用授权到目标多维表格。
3. 点击插件面板顶部的“飞书配置”。
4. 填写 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、飞书多维表格完整链接。
5. 点击“保存配置”。
6. 采集并筛选笔记后，点击“导入飞书”。

导入时，插件会使用封面链接下载图片后上传到飞书，并写入“封面”附件字段。请将“封面”设置为飞书多维表格的附件类型；飞书中不再写入“封面链接”。如果某张小红书图片链接已过期或无法访问，该条笔记仍会导入，但该条“封面”字段为空，面板会提示图片上传失败数量。

正文抓取是可选步骤，不会阻止导入飞书。未抓取正文、正文为空或正文抓取失败的笔记仍会正常导入，对应的“正文”字段留空；抓取成功的笔记会写入正文内容。抓取过程会逐条打开详情悬浮层，等待正文和封面链接加载完成后再关闭；如果主页使用虚拟列表，插件会自动滚动搜索目标卡片。

多维表格链接支持 `/base/{app_token}` 链接，也支持飞书 wiki 包裹的 `/wiki/{token}` 链接，例如：

```text
https://example.feishu.cn/wiki/K5WkwD5pJiXwV3knuEMce4PInif?table=tblxxxx&view=vewxxxx
```

链接必须包含 `table=` 参数。请打开目标数据表后复制浏览器地址栏中的完整链接。

安全提示：`FEISHU_APP_SECRET` 会保存到本机 Chrome 扩展存储中，适合个人本机使用，不适合打包公开分发。

## 导出格式

文件名格式：

```text
作者昵称_笔记数量.xlsx
```

列顺序：

1. 标题
2. 作者
3. 笔记形式
4. 点赞
5. 原文链接
6. 正文
7. 封面链接

点赞数会尽量数字化，例如：

- `1万` -> `10000`
- `1.2万` -> `12000`
- `356` -> `356`

无法识别时留空。

## 限制

- 第一版只支持用户主页，不支持搜索页、话题页、发现页。
- 采集阶段不直接下载图片文件；导入飞书时会按封面 URL 上传封面图片，评论、收藏数、发布时间仍不采集。
- 面板缩略图用于预览；导出 Excel 的是封面图片 URL，导入飞书时会另外上传封面图片文件。
- 分屏布局只在面板打开期间生效，关闭面板后会恢复小红书页面原始宽度。
- 正文抓取依赖小红书详情悬浮层的页面结构；页面结构变化时需要维护选择器。
- 封面 URL 可能因签名或过期而失效。
- 正文抓取按单条串行执行，不支持并发抓取。
- 自动滚动有内部安全上限，用于避免异常页面无限滚动。
- 小红书页面结构可能变化，如果页面 DOM 调整，选择器可能需要维护。
