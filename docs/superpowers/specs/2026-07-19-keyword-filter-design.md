# 关键词筛选设计

## 目标

在 Side Panel 中增加关键词输入框，按标题或正文是否包含关键词筛选笔记，并让 Excel 导出和飞书导入只使用筛选后的结果。

## 规则

- 匹配不区分大小写。
- 标题命中或正文命中即可保留。
- 关键词为空时不增加关键词过滤。
- 正文尚未抓取时，仍可通过标题命中；无法通过未存在的正文内容命中。
- 现有点赞阈值、内容类型和点赞排序规则保持不变，关键词过滤与它们叠加。

## 实现

- `sidepanel.html` 增加关键词文本输入框。
- `sidepanel.js` 在状态中保存关键词，并在 `filteredRows()` 中加入标题/正文的大小写不敏感包含匹配。
- `rowsForExternalUse()`、Excel 导出和飞书导入继续复用 `displayRows()`，因此自动只处理最终筛选结果。
- `sidepanel.css` 为输入框复用现有字段样式，适配 Side Panel 宽度。
- 测试覆盖空关键词、标题命中、正文命中、大小写差异和未命中场景。

## 不在范围内

- 不修改采集、正文抓取和飞书接口逻辑。
- 不拆分多个关键词，也不改变关键词的输入格式。
