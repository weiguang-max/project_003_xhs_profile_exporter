# 发布时间采集设计

## 目标

从小红书笔记详情悬浮层读取发布时间，并将原始显示文本同步到面板列表、Excel 和飞书多维表格。

## 方案

- 在详情层内读取 `.bottom-container .date` 的 `textContent`。
- 只去除节点首尾空白，不推断年份、不解析日期、不修改格式；例如 `07-02` 保持为 `07-02`。
- 发布时间为空时保存空字符串，不影响正文、封面和其他字段的采集或导入。
- 采集结果统一使用 `publishTime` 字段，面板和 Excel 直接消费该字段，飞书写入文本字段“发布时间”。

## 兼容性

- 详情抓取的成功条件不增加发布时间要求，避免因页面没有日期而导致整条笔记抓取失败。
- 飞书目标表需要新增文本字段“发布时间”；缺少该字段时，沿用现有字段校验并给出明确错误。

## 验证

- 单元测试覆盖日期读取、原样保存和飞书字段映射。
- 运行脚本语法检查、测试、`git diff --check` 和扩展压缩包校验。
