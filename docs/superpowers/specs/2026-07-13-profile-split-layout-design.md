# 博主主页分屏布局设计

## 目标

采集面板打开后，右侧工具栏固定占用一列宽度，小红书博主主页使用剩余宽度重新布局，不再被工具栏覆盖。关闭面板后，页面恢复打开前的样式。

## 方案

- 保留当前标签页和右侧固定工具栏，不创建新窗口或新标签页。
- 打开面板时缩窄 `body`，并让小红书主容器 `#app` 使用“视口宽度减去面板宽度”，设置 `min-width: 0`、`box-sizing: border-box`，并隐藏横向溢出。
- 记录 `body`、`#app` 和页面横向溢出相关的原始内联样式，关闭面板时逐项恢复。
- 采集面板继续使用 Shadow DOM 和独立纵向滚动；笔记详情悬浮层、真实鼠标点击和导出逻辑不变。

## 验证

- 现有正文、点击定位和详情工具测试继续通过。
- 扩展脚本通过语法检查，重新生成的 `extension.zip` 通过压缩包校验。
- 手动确认面板打开时主页不被遮挡，关闭面板后页面宽度恢复。
